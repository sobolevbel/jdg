# Full-Service Accounting for JDG

This guide is written for people who run their JDG themselves — and for most
IT freelancers with one invoice a month that is genuinely enough.
But doing it yourself doesn't suit everyone, or every situation.

## When you need an accountant

- No time or desire to deal with declarations, contributions and deadlines —
  you want to work, not administrate.
- You are a [VAT payer](registration_vat.md): deductions, JPK_V7M, korekty and
  the mandatory [KSeF](declarations_vat.md) noticeably raise the cost of a mistake.
- Non-standard situations: several activity types with different
  [ryczałt](taxes.md) rates, goods instead of services, employees, a company car.
- You are preparing for [legalization](legalization.md) — you need error-free
  certificates and statements for the urząd.
- Polish-only correspondence with a typical local accountant is a barrier:
  you want to ask questions in a language you're comfortable with and get
  answers you understand.

If none of these apply to you — run the books yourself:
start with [inFakt setup](infakt_settings.md) or
[wFirma](wfirma_settings.md) and the [monthly routine](workflow.md).
